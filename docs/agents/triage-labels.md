# Triage labels

The skills speak of five triage roles. This page maps each role to the label string used in `binary-bridges-co/my-pets-page`. The names are the defaults.

| Role in mattpocock/skills | Label in this tracker | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | The maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent working alone |
| `ready-for-human` | `ready-for-human` | Requires a person to implement it |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role ("apply the AFK-ready triage label"), use the label string from this table.

## Other labels

GitHub's defaults (`bug`, `documentation`, `enhancement` and the rest) stay as they are; no skill depends on them.

There are no `wayfinder:` labels here: a wayfinder map is charted in `bb-context` (see [issue-tracker.md](issue-tracker.md#wayfinding-operations)). Creating any other label needs the owner's approval.
